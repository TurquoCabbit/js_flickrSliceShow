# flickrSliceShow

這是一個Flickr相片輪播工具，會以隨機順序播放 Flickr 帳戶中所有可公開瀏覽的相片。

## 開啟輪播

**[▶ 開啟 flickrSliceShow](https://turquocabbit.github.io/js_flickrSliceShow/)**

您也可以下載`index.html`到電腦上後，直接在瀏覽器中開啟。

## 使用方式

1. 前往 [Flickr API 應用程式申請頁面](https://www.flickr.com/services/apps/create/apply/)，取得 Flickr API 金鑰。
2. 輸入 API 金鑰和 Flickr 帳戶。帳戶欄位接受 Flickr 使用者 ID（NSID）、個人檔案網址或自訂網址名稱。
3. 選擇每張相片的播放時間：5、10、30 或 60 秒（預設為 10 秒）。選擇 **自訂…** 可設定 1 秒至 1 天（86,400 秒）的播放時間。
4. 點選 **載入完整相簿**。輪播會載入該帳戶的公開相片，並以隨機順序播放，每張相片播放一次後才會重新洗牌。
5. 點選全螢幕按鈕或按下 **F**，讓相片顯示區進入全螢幕。相片一開始會完整顯示；按下 **C** 可讓相片填滿畫面，但可能會裁切相片。

僅能顯示可公開瀏覽的相片。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `←` | 上一張相片 |
| `→` | 下一張相片 |
| `Space` | 暫停或繼續播放 |
| `F` | 進入或離開全螢幕 |
| `C` | 切換完整顯示相片或讓相片填滿畫面（僅限全螢幕模式） |
| `Esc` | 離開全螢幕 |

全螢幕播放時，操作控制項會自動隱藏。移動滑鼠游標或輕觸螢幕即可再次顯示。
